# claude-shared-rules ドキュメント

共有 Claude Code ルールを入れる方法、プロジェクトに導入する方法、上書きする方法をまとめた目次。

## ガイド

| 文書 | 内容 |
|---|---|
| [セットアップ](SETUP.md) | このマシンや新しいマシンへの導入、確認、更新、削除、既知の制約 |
| [共有ルールの導入](ADOPTING.md) | 新規・既存のプロジェクトに共有ルールを入れるためのチェックリスト |
| [上書きとオプトアウト](OVERRIDES.md) | プロジェクトで共有ルールに足す・置き換える・外す方法 |

## ソースファイル（英語のみ）

| 場所 | 内容 |
|---|---|
| [`rules/`](../../rules/) | Claude が全プロジェクトで読み込むルールファイル。ルールファイル以外は置かない |
| [`templates/`](../../templates/) | 導入時にプロジェクトへコピーするファイル：`CLAUDE.md` の雛形、目次のテンプレート、文書ヘッダーの断片 |
| [`optional/`](../../optional/) | リンクしたユーザーにだけ効くオプションのルール。例：会話を関西弁にする |
| [`prompts/`](../../prompts/) | プロジェクトの Claude Code セッションに実行させる作業手順。例：ドキュメントを読みやすく書き直す |

## 作業用ドキュメント（英語のみ）

まだない。作る場合は `docs/working/` に置く。
