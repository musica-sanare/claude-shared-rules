# claude-shared-rules ドキュメント

共有 Claude Code ルールのインストール、プロジェクトへの導入、上書きの方法を説明します。

## ガイド

| 文書 | 説明 |
|---|---|
| [セットアップ](SETUP.md) | このマシンや新しいマシンへのインストール、確認、更新、アンインストール、既知の制約。 |
| [共有ルールの導入](ADOPTING.md) | 新規または既存のプロジェクトに共有ルールを導入するためのチェックリスト。 |
| [上書きとオプトアウト](OVERRIDES.md) | プロジェクトが共有ルールに追加する、置き換える、または適用を外す方法。 |

## ソースファイル（英語のみ）

| 場所 | 説明 |
|---|---|
| [`rules/`](../../rules/) | Claude がすべてのプロジェクトで読み込むルールファイル。ここにはルールファイルだけを置く。 |
| [`templates/`](../../templates/) | プロジェクトが導入時にコピーするファイル：`CLAUDE.md` の雛形、ドキュメント索引のテンプレート、文書ヘッダーのスニペット。 |
| [`prompts/`](../../prompts/) | 各プロジェクトの Claude Code セッションが従う作業手順。例：ドキュメントを読みやすく書き直す。 |

## 作業用ドキュメント（英語のみ）

まだありません。作業用ドキュメントは `docs/working/` に置きます。
