# Language

- Talk to the owner in Japanese: questions, progress updates, explanations, test summaries, handoff notes, and the explanation around commit proposals.
- In conversation, use natural, polite Japanese (です・ます). The plain form required by `writing-style.md` is for documents only.
- Write everything stored in a repository in English: docs, README, ADRs, setup instructions, code comments, docstrings, commit messages, and PR descriptions. The only exception is the Japanese doc translations required by `documentation.md`.
- Write code comments in English. Prefer clear naming over comments; do not add redundant comments.
- Mark open items that need the owner's confirmation as `要確認`.
- Product UI localization (supported locales, translation files, locale handling) is out of scope here; each project defines its own.
